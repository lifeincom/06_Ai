# product-detail-page-auto-skill v3.0

## 목적
상품정보 + 실제 상품 이미지 → 입력 표준화 → 레퍼런스 → 웹 리서치 → 레이아웃 → Figma 편집형 초안 → QA/출력.

## 기본 사용 예
`상세페이지 전체 자동 진행. 상품명: PK 반팔 티셔츠 / 브랜드: 비버리힐스폴로클럽 / 카테고리: 의류 / 설명: 시원하고 편안한 스탠다드핏 PK 티셔츠 / 실제 상품 이미지: 첨부. Figma 팀: 5changhoon.`

## 구성
- SKILL.md: 실행 원칙 및 순서
- references/: 사용자 제공 원본 5개 지침서
- config.json: 기본 설정
- schemas/: 표준 데이터 JSON Schema
- QA_CHECKLIST.md: 검수
- CHANGELOG.md: 원본 대비 변경 기록
- examples/: 샘플 입력

## 주의
이 ZIP은 재사용 가능한 Skill 소스 패키지다. ZIP 자체가 Figma 또는 웹 리서치 계정에 자동 접근하는 실행 프로그램은 아니다. 실행에는 ChatGPT에서 필요한 도구 연결과 권한이 별도로 필요하다.
