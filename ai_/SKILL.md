## 1. 지침서 개요 및 작동 원리

### 이 지침서는 무엇인가?

상품정보가 담긴 엑셀 파일 하나를 Claude AI에 업로드하면, 웹 검색 · 기획 · 디자인 초안 생성까지 자동으로 진행되는 워크플로우의 사용 방법을 설명합니다. 개발 지식 없이도 마케터, 기획자, 디자이너 누구나 바로 사용할 수 있습니다.

### 핵심 작동 원리

| 항목 | 내용 |
|------|------|
| **진입점** | Claude AI 채팅창에 엑셀 파일 업로드 + `'상세페이지 만들어줘'` 입력 |
| **자동화 범위** | 웹검색 수집 · 기획안 작성 · Figma 초안 생성 — 3단계 AI 자동 처리 |
| **사람 개입** | ① 기획안 검토/수정 입력 ② 상품 이미지 업로드 ③ Figma 후편집 |
| **최종 결과물** | 상품명으로 저장된 Figma 파일 (디자이너 후편집용 초안) |
| **소요 시간** | 입력 완료 기준 약 5~10분 (상품 복잡도에 따라 상이) |

> ⚠️ **주의** 이 워크플로우는 Figma **초안 자동생성**이 목적입니다. 최종 납품물은 디자이너가 Figma에서 후편집 후 확정합니다.

## 2. 전체 프로세스 한눈에 보기

| STEP | 단계명 | 담당 | 핵심 산출물 |
|:----:|--------|:----:|------------|

| 2 | 웹검색 & 이미지 수집 | AI 자동 | 경쟁사 정보 + 상품 이미지 URL 목록 |
| 3 | 기획안 자동 생성 | AI 자동 | 섹션 구성 + 카피 초안 + 레이아웃 제안 |

## 3. STEP 1 — 상품정보 엑셀 입력

### 담당: 사람 직접

### 사용자가 할 일

1. 동봉된 `상세페이지_상품정보_입력템플릿.xlsx` 파일을 열어 **C열(입력칸)** 에 상품 정보를 입력합니다.
2. **★ 표시 필수항목**을 모두 입력합니다.
   - 상품명 · 카테고리 · 정상가 · 판매가 · 핵심 판매 포인트 · 타깃 고객
3. 레퍼런스 URL이나 이미지가 있으면 ⑤ 섹션에 함께 입력합니다.
4. 제출 전 체크리스트(3번째 시트)를 확인합니다.
5. Claude AI 채팅창에 파일을 업로드하고 아래 프롬프트를 입력합니다.

### 시작 프롬프트 예시

```
첨부한 엑셀 파일의 상품정보를 분석해서 상세페이지를 자동으로 만들어줘.
레퍼런스 URL: [있으면 입력, 없으면 생략]
디자인 스타일: [미니멀 / 스트릿 / 럭셔리 / 캐주얼 / 스포티]
```

### 입력 항목 요약

| 섹션 | 포함 항목 |
|------|----------|
| ① 기본 정보 | 상품명, 브랜드, 카테고리, URL, 출시일 |
| ② 가격 정보 | 정상가, 판매가, 할인율, 배송비 |
| ③ 상품 상세 | 판매 포인트, 상세 설명, 소재, 사이즈, 색상 |
| ④ 타깃 & 마케팅 | 타깃 고객, 감성 키워드, 경쟁 상품, 채널, 프로모션 |
| ⑤ 이미지 & 레퍼런스 | 레퍼런스 URL, 디자인 스타일, 배경 컬러, 이미지 장수 |

## 4. STEP 2 — AI 웹검색 & 이미지 수집

### 담당: AI 자동

### Claude가 자동으로 처리하는 내용

- 입력된 상품명 · 브랜드 · 카테고리를 기반으로 웹 검색을 수행합니다.
- 경쟁 상품의 상세페이지 구성, 가격대, 핵심 메시지를 분석합니다.
- 상품 관련 공식 이미지, 사용 예시 이미지 URL을 수집합니다.
- 카테고리 트렌드 키워드와 소비자 리뷰 패턴을 참고합니다.
- 수집된 정보를 기획안 생성의 인풋으로 자동 전달합니다.

### 수집 정보 유형

| 유형 | 내용 |
|------|------|
| **경쟁사 정보** | 입력된 경쟁 상품의 판매 포인트, 가격, 상세페이지 구성 방식 |
| **트렌드 키워드** | 해당 카테고리에서 현재 소비자가 중시하는 가치·기능 키워드 |
| **참고 이미지** | 레퍼런스 URL에서 추출한 섹션 구성 패턴 및 비주얼 스타일 |
| **리뷰 인사이트** | 유사 상품 구매 후기에서 반복되는 긍정/부정 포인트 |

> ⚠️ 이 단계는 완전 자동입니다. 별도 입력 불필요. 단, 검색 결과가 부족할 경우 Claude가 추가 정보를 요청할 수 있습니다.

---

## 5. STEP 3 — 기획안 자동 생성

### 담당: AI 자동

### Claude가 자동으로 처리하는 내용

- STEP 1 입력 정보 + STEP 2 수집 데이터를 종합 분석합니다.
- 상세페이지 섹션 구성 (히어로 · 특징 · 스펙 · 후기 · CTA 등)을 설계합니다.
- 각 섹션의 헤드카피, 서브카피, 본문 텍스트 초안을 작성합니다.
- 레퍼런스 URL의 레이아웃 패턴을 분석해 유사 구조를 제안합니다.
- 컬러 팔레트, 폰트 분위기, 이미지 배치 방향을 함께 제안합니다.

### 기획안 산출물 구성

| 항목 | 내용 |
|------|------|
| **섹션 구조** | 히어로 배너 / USP 3~5개 / 상세 스펙 / 사용 장면 / CTA 버튼 |
| **카피 초안** | 헤드라인, 서브카피, 본문 텍스트 (한국어 기준) |
| **레이아웃 방향** | 좌우 배치, 풀스크린, 그리드 등 섹션별 구조 설명 |
| **디자인 제안** | 배경 컬러, 강조 컬러, 폰트 분위기, 이미지 톤 방향 |
| **모바일 대응** | 모바일 우선 또는 PC/모바일 병행 여부 권장 방향 |

## 6. STEP 4 — 기획안 검토 & 수정

### 담당: 사람 직접

### 사용자가 할 일

1. Claude가 출력한 기획안을 읽고 수정이 필요한 부분을 파악합니다.
2. 수정 내용을 채팅창에 자유롭게 입력합니다. (형식 무관)
3. Claude가 수정 반영 후 업데이트된 기획안을 재출력합니다.
4. 만족스러우면 **`'기획안 확정'`** 을 입력해 다음 단계로 넘어갑니다.

### 수정 요청 프롬프트 예시

```
수정 요청 예시:
• '히어로 배너 카피를 더 감성적으로 바꿔줘'
• '가격 강조 섹션을 상단으로 올려줘'
• '경쟁사 대비 차별화 섹션을 추가해줘'
• '모바일 최적화 기준으로 섹션 순서를 재배치해줘'

확정 시: '기획안 확정. 다음 단계 진행해줘'
```

> ⚠️ 수정은 여러 번 반복 가능합니다. **`'기획안 확정'`** 입력 전까지 Figma 생성을 시작하지 않습니다.

## 7. STEP 5 — 상품 이미지 업로드

### 담당: 사람 직접

### 사용자가 할 일

1. 기획안 확정 후 Claude가 이미지 업로드를 요청합니다.
2. 준비된 상품 이미지를 채팅창에 업로드합니다.
3. 이미지가 여러 장이면 한 번에 모두 업로드합니다.
4. 각 이미지의 용도를 간단히 설명하면 배치 품질이 향상됩니다.

### 이미지 준비 기준

| 항목 | 기준 |
|------|------|
| **권장 해상도** | 최소 1200px 이상 (가로 기준). Figma 초안용이므로 원본 권장 |
| **권장 형식** | JPG, PNG, WEBP 모두 가능. 배경 제거가 필요하면 PNG 투명 권장 |
| **권장 장수** | 최소 5장 이상. 히어로 1장 + 디테일 2~3장 + 사용 장면 1~2장 |
| **파일명 팁** | `01_hero.jpg`, `02_detail.png` 등 순서와 용도를 파일명에 표기 권장 |
| **이미지 없을 때** | Claude가 수집한 웹 이미지 URL로 대체 배치 (품질 저하 가능) |

### 업로드 후 입력 예시

```
이미지 업로드 완료.
01번은 히어로 배너용, 02~04번은 디테일컷, 05번은 착용 예시야.
```

## 8. STEP 6 — Figma 초안 자동 생성

### 담당: AI 자동

### Claude가 자동으로 처리하는 내용

- 1~5단계의 모든 정보를 종합해 Figma 파일을 생성합니다.
- 파일명은 입력된 **상품명으로 자동 설정**됩니다.
- 기획안의 섹션 구조 · 카피 · 이미지 배치를 Figma 레이어로 구현합니다.
- 너비 **900px**, 최소 높이 **12,000px** 기준의 상세페이지 아트보드를 생성합니다.
- 컬러 스타일, 텍스트 스타일을 Figma 로컬 스타일로 등록합니다.

### Figma 초안 구성 내용

| 항목 | 내용 |
|------|------|
| **아트보드** | 너비 900px · 최소 높이 12,000px (콘텐츠 양에 따라 자동 확장) |
| **레이어 구조** | 섹션별 그룹화 (Hero / Feature / Spec / Review / CTA) |
| **텍스트** | 기획안 카피 전체 반영. 폰트는 Noto Sans KR 기본 적용 |
| **이미지** | 업로드된 상품 이미지 배치. 누락 시 플레이스홀더로 대체 |
| **컬러 스타일** | 주색상 · 보조색상 · 배경색 Figma 로컬 스타일로 등록 |
| **파일명** | 입력된 상품명 자동 적용. 예: `나이키 에어맥스 270.fig` |

## 9. STEP 7 — 미리보기 출력

### 담당: AI 자동

### Claude가 자동으로 처리하는 내용

- 생성된 Figma 파일의 주요 섹션을 채팅창 미리보기로 출력합니다.
- PC 버전과 모바일 버전 각각의 스크린샷을 보여줍니다.
- Figma 파일 링크를 공유해 바로 열어볼 수 있도록 안내합니다.
- 후편집을 위한 디자이너 인계 체크리스트를 함께 출력합니다.

> ⚠️ 미리보기는 참고용입니다. 최종 품질 확인은 Figma에서 직접 열어 확인하세요.

## 10. 디자이너 후편집 가이드

AI가 생성한 Figma 초안은 구조와 카피의 뼈대입니다. 디자이너는 아래 항목을 중심으로 후편집을 진행합니다.

| 우선순위 | 편집 항목 | 주요 작업 내용 |
|:--------:|----------|--------------|
| 🔴 HIGH | 이미지 정리 | 플레이스홀더 교체, 이미지 비율 조정, 마스킹 |
| 🔴 HIGH | 폰트 적용 | 브랜드 가이드라인 폰트로 교체, 자간·행간 미세 조정 |
| 🔴 HIGH | 컬러 정교화 | 브랜드 컬러로 수정, 그라디언트 및 투명도 적용 |
| 🟡 MID | 레이아웃 정밀화 | 여백 통일, 그리드 정렬, 반응형 제약 설정 |
| 🟡 MID | 카피 수정 | 최종 확정 카피로 교체, 오탈자 검수 |
| 🟡 MID | 컴포넌트화 | 반복 요소 컴포넌트 전환, Auto Layout 적용 |
| 🟢 LOW | 인터랙션 추가 | 호버 효과, 스크롤 애니메이션 프로토타입 |
| 🟢 LOW | 최종 내보내기 | PNG/SVG 에셋 내보내기, 개발자 핸드오프 설정 |

## 11. FAQ & 트러블슈팅

**Q. 엑셀 필수항목을 일부 비우면 어떻게 되나요?**

A. Claude가 비어있는 항목을 웹 검색으로 보완하거나, 해당 항목을 생략한 채 기획안을 생성합니다. 단, 상품명 · 카테고리 · 판매가가 없으면 작업을 시작할 수 없으니 반드시 입력하세요.

---

**Q. 레퍼런스 URL 없이도 진행 가능한가요?**

A. 네. 레퍼런스가 없으면 Claude가 카테고리와 디자인 스타일을 기반으로 자동으로 구성을 설계합니다. 다만 레퍼런스가 있을수록 원하는 방향에 가까운 결과가 나옵니다.

---

**Q. 기획안 수정을 몇 번까지 할 수 있나요?**

A. 횟수 제한 없습니다. `'기획안 확정'` 입력 전까지 자유롭게 수정 요청하세요.

---

**Q. Figma 계정이 없어도 되나요?**

A. Figma 파일 생성에는 Claude의 Figma MCP 연결이 필요합니다. Figma 무료 계정을 생성한 뒤 Claude와 연동해야 합니다. 연동 방법은 Claude 설정 > 연결된 앱에서 Figma를 추가하세요.

---

**Q. 이미지를 업로드하지 않으면?**

A. Claude가 웹에서 수집한 이미지 URL 또는 플레이스홀더로 대체합니다. Figma 초안은 생성되지만 실제 상품 이미지 없이 생성되어 후편집 작업이 늘어납니다.

---

**Q. 완성된 Figma 파일은 어디서 확인하나요?**

A. Claude가 채팅창에 Figma 파일 링크를 공유합니다. 클릭하면 Figma 에디터에서 바로 열립니다.

---

**Q. 아트보드 사이즈는 어떻게 되나요?**

A. Figma 초안은 너비 900px · 최소 높이 12,000px 단일 아트보드로 생성됩니다. 섹션이 많아 콘텐츠가 길어지면 높이가 자동으로 늘어납니다. 모바일 별도 아트보드가 필요하면 기획안 확정 전에 요청하세요.
