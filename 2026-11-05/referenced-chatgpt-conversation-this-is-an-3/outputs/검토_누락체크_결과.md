# 상품정보입력양식 검토 결과

검토일: 2026-11-05  
대상 제품: 패스츄리 오징어 200g / 원본 식별값: 01_패스츄리오징어

## 실제 파일 확인

참조 대화의 첨부파일 `상품정보입력양식.xlsx`를 직접 열어 확인했다. 시트는 `Sheet1` 1개이며, 실제 입력 범위는 A1:B15이다. A열은 항목, B열은 입력정보이고, C:O에는 입력값이 없다. A1:B1은 제목과 식별값, A2:B2는 열 제목, A3:B15는 제품정보 13개 항목이다. 병합 셀과 삽입 이미지는 없다.

기존 13개 항목은 모두 값이 있지만, 값이 있다는 사실을 제품정보 검증 완료로 보지는 않았다. 원본 셀별 검토 결과는 개선 엑셀의 `검토_누락체크`에 모두 기록했다. 판정은 확인 필요 5개, 보완 필요 7개, 오류 의심 1개다.

## 우선 확인할 내용

1. **원재료 함량 합계:** B7의 수치 81 + 10 + 6 + 1 + 1.2 + 0.1 + 1 = **100.3%**다. 버터 함량은 따로 기재되어 있지 않다. 동일 기준의 배합인지, 복합원료 내부 비율이 섞였는지, 오기인지 제조사 배합표와 라벨로 확인해야 한다. 수치를 임의로 고치지 않았다.
2. **소브산 1%:** 명칭·단위·배합 기준을 원본 라벨 및 제조사 자료와 대조할 필요가 있다. 이 입력값만으로 허용기준 위반이나 안전성을 판정하지 않았다.
3. **소비기한:** B6의 ‘별도표기일까지’에는 실제 날짜, 표시 위치, 제조일 기준 기간과 출고 기준이 없다. 날짜 인쇄 사진과 공급업체 기준이 필요하다.
4. **보관방법:** B12의 ‘냉장냉동’은 조건이 모호하다. 미개봉·개봉 후·장기 보관별 온도와 기간, 실제 배송 온도를 확인해야 한다.
5. **포장재질·환경성 표현:** B13의 ‘친환경소재 폴리’는 정확한 접촉면 재질을 특정하지 못한다. 포장 규격서를 요청하고, 친환경 표현은 증빙 확보 전 광고 사용을 보류한다.
6. **알레르기:** A14 ‘알래르기’는 개선 필드에서 ‘알레르기’로 정리했다. B14 ‘오징어우유함유’는 오징어·우유를 구분하되, 복합원재료와 교차접촉 주의문까지 확인해야 한다. 원문은 보존했다.
7. **교환·상담:** B11 ‘구입처’만으로 접수 절차·주소·비용·조건이 확인되지 않는다. B10 전화번호가 실제 소비자상담 번호인지 확인한다.

## 추가 입력필드와 구성

개선 엑셀은 총 7개 시트로 구성했다.

| 시트 | 제공 내용 |
|---|---|
| Sheet1 | 원본 13개 항목과 입력값 유지 |
| 검토_누락체크 | 원본 셀 위치, 기존 입력값, 판정, 보완 내용, 필요한 근거 |
| 개선_입력필드 | 기존 13개 + 추가 26개, 총 39개 필드. 확정값·근거·검증 상태·처리 결과 |
| 식품표시_체크 | 표시·고지 15개 검토 항목, 적용 조건, 현재 판정, 추가 입력·검토란 |
| 섹션별_기획 | 12개 섹션 제안, 목적·내용·실제 이미지·선행 확인·확정 카피·배치·승인란 |
| QA_체크 | 사실·안전·권리·광고·모바일·디자인·납품 등 15개 검사 항목 |
| 사용안내_출처 | 사용법, 판정 의미, 검토 범위, 공식 출처와 확인 한계 |

추가 26개 필드는 제품정보 9개, 실제 이미지·로고 6개, 카피 5개, 디자인 시스템 6개로 구분했다. 섹션 기획과 식품 표시, QA에는 별도의 입력란을 제공한다.

실제 패키지·뒷면 라벨·내용물·결/단면·구성·크기 비교 사진, 로고 원본과 사용권 정보가 이 파일에 없다. 맛·식감·섭취 방법·고객·장점·브랜드 디자인 값도 확정되지 않았다. 확정값을 창작하지 않고 빈 입력란과 작성 기준을 제공했다. 12개 섹션은 수정 가능한 기획 제안이며 최종 승인된 제작안은 아니다.

## 식품 표시 검토 범위

국내 판매 가공식품으로 잠정 분류하여 포장 표시와 온라인 상품정보 고지를 구분했다. 영양정보, 수입 관련 정보, 유전자변형식품 표시, 추가 안전 표시 등은 제품 유형·제조 공정·예외·적용 시점에 따라 판단하도록 ‘적용 여부 미확인’으로 남겼다. ‘자료 없음’을 ‘해당없음’으로 바꾸지 않았다.

공식 자료는 [식약처 식품등의 표시기준 고시전문 게시](https://www.mfds.go.kr/brd/m_211/view.do?seq=14968), [식품표시광고법 시행규칙](https://www.law.go.kr/LSW/lsInfoP.do?lsId=013475), [식품표시광고법 제8조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029094685)를 확인했다. [온라인 상품정보 제공 고시](https://www.law.go.kr/행정규칙/전자상거래등에서의상품등의정보제공에관한고시)는 공식 페이지를 확인했으나 본문 추출에 제한이 있어 세부 원문 최종 대조가 남아 있다. 원산지 적용 대상과 표시방법도 공급자료·해당 규정 대조가 필요하다. 이 결과는 입력 양식과 자료 보완을 위한 검토이며, 제품의 법적 적합성 최종 판정은 아니다.

## 입력 방법과 검증 결과

- `개선_입력필드`의 노란 칸에 확정값(F열), 근거(H열), 검증 상태(I열)를 입력한다. 세 조건이 충족되어야 J열이 ‘확인완료’가 된다. ‘해당없음’은 H열에 사유가 있어야 한다.
- `QA_체크`는 결과가 ‘통과’여도 증빙·담당자·검토일이 없으면 ‘기록 보완’으로 남는다.
- 원본 복사본은 원본 파일과 SHA-256 해시가 동일함을 확인했다. 개선본의 Sheet1 A1:O15 값도 원본과 일치한다. 개선본은 내보내기 과정에서 일부 서식 속성이 정규화되므로 정확한 원본 서식 보존본은 별도 원본 파일을 사용한다.
- 생성 엔진에서 수식을 재계산하고 오류를 검색했다. 확정값과 확인완료만 입력하면 ‘근거 필요’, 근거까지 입력하면 ‘확인완료’가 되는 것을 시험한 뒤 시험값을 제거했다.
- 각 시트의 주요 범위를 이미지로 확인하고, 저장한 엑셀의 시트·값·수식·입력 목록을 다시 읽어 점검했다. 데스크톱 Microsoft Excel에서 직접 열어 재계산하는 검증은 수행하지 않았다.

먼저 제조사 라벨·배합표, 소비기한과 보관 기준, 실제 제품 사진을 확보하면 우선 확인 항목을 해결하고 상세페이지 제작으로 이어갈 수 있다.
