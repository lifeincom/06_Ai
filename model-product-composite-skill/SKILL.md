# Model Product Composite Skill

## 사용 목적

이 스킬은 사용자가 다음과 같은 요청을 할 때 사용한다.

- 모델 이미지에 티셔츠, 의류, 모자, 안경, 가방 등 상품 이미지를 합성
- 남성/여성 모델별로 다른 상품 이미지를 착용 합성
- 기존 배경, 포즈, 화면 비율, 레이아웃을 유지한 상품 착용컷 제작
- 로고 크기, 로고 색상, 상품 컬러, 인물 크기, 여백 확장 등 부분 수정
- 쇼핑몰 상세페이지, 상품 대표 이미지, 광고 소재용 합성 이미지 제작

## 기본 원칙

1. 실제 상품 이미지를 최우선으로 사용한다.
2. 상품의 형태, 컬러, 로고, 패턴, 재질감은 임의로 바꾸지 않는다.
3. 원본 모델 이미지의 배경, 포즈, 카메라 앵글, 화면 비율은 사용자가 변경을 요청하지 않는 한 유지한다.
4. 합성 대상이 명확하면 추가 질문 없이 바로 진행한다.
5. 상품 이미지가 여러 장이면 사용자의 번호 지시를 따른다.
6. 남성/여성, 좌/우, 모델별 상품 매칭이 지정되면 정확히 반영한다.
7. 사용자가 “그 외 변형 없음”, “유지”, “현재 이미지 그대로”라고 말하면 수정 지시 외 요소는 건드리지 않는다.
8. 로고 크기, 위치, 색상 수정 요청은 상품 전체 변형보다 우선한다.
9. 이미지 확장 요청이 있으면 인물 크기는 유지하고 배경만 자연스럽게 확장한다.
10. 결과물은 쇼핑몰에서 사용할 수 있도록 과장된 AI 느낌보다 자연스러운 실사 합성을 우선한다.

## 입력 받는 정보

사용자가 제공할 수 있는 입력은 다음과 같다.

- 모델 이미지: 배경과 포즈 기준이 되는 이미지
- 상품 이미지: 모델에게 입히거나 착용시킬 상품 이미지
- 상품 매칭: 예) 남성은 화이트, 여성은 블랙
- 모델 변경 여부: 예) 외국인 모델, 한국인 모델, 남녀 모델 유지 등
- 유지 조건: 배경 유지, 자세 유지, 화면 비율 유지, 인물 크기 유지
- 수정 조건: 로고 크기, 로고 색상, 상품 컬러, 텍스트 제거, 여백 확장 등
- 출력 조건: 이미지 사이즈, 비율, 용도

## 작업 전 판단 규칙

### 충분히 명확한 경우

다음 조건이 충족되면 질문하지 않고 바로 이미지 생성 또는 편집을 진행한다.

- 모델 이미지가 있고 상품 이미지가 있다.
- 어느 상품을 어느 모델에게 적용할지 알 수 있다.
- 유지해야 할 요소가 명시되어 있다.

### 확인이 필요한 경우

다음 경우에는 짧게 하나만 질문한다.

- 모델 이미지가 없는데 기존 이미지에 합성하라고 하는 경우
- 상품 이미지가 없거나 어떤 상품이 어느 모델용인지 전혀 구분되지 않는 경우
- 출력 사이즈가 반드시 필요한 작업인데 사이즈가 빠진 경우

단, 사용자가 “알아서”, “기본값”, “승인 없이 진행”이라고 말하면 합리적인 기본값으로 진행한다.

## 기본 워크플로우

1. 업로드된 이미지 역할을 구분한다.
   - 1번: 기준 모델/배경 이미지
   - 2번 이후: 상품 이미지
   - 사용자가 다르게 지정하면 사용자 지시를 우선한다.

2. 합성 매칭을 정리한다.
   - 예: 남성 모델 = 화이트 상품
   - 예: 여성 모델 = 블랙 상품
   - 예: 왼쪽 모델 = 라이트블루, 오른쪽 모델 = 화이트

3. 유지 조건을 확인한다.
   - 배경 유지
   - 포즈 유지
   - 인물 크기 유지
   - 화면 비율 유지
   - 레이아웃 유지
   - 상품 원형 유지

4. 이미지 편집 지시를 작성한다.
   - 상품을 모델 몸의 형태와 주름에 맞게 자연스럽게 합성한다.
   - 로고와 그래픽은 왜곡을 최소화한다.
   - 목선, 소매, 밑단, 어깨선이 자연스럽게 맞도록 처리한다.
   - 조명, 그림자, 원근감, 색온도를 원본 이미지와 맞춘다.
   - 필요 시 모델을 지정된 국적/인상으로 변경하되 포즈와 배경 구도는 유지한다.

5. 생성 후 자체 검수한다.
   - 상품 컬러가 맞는가?
   - 모델별 상품 매칭이 맞는가?
   - 로고 크기와 색상이 맞는가?
   - 배경과 포즈가 불필요하게 바뀌지 않았는가?
   - 화면 비율이 유지되었는가?
   - 인물 일부가 잘렸는가?

6. 문제가 있으면 전체 재작업하지 않고 해당 오류만 수정한다.

## 이미지 생성/편집 프롬프트 작성 규칙

이미지 도구를 사용할 때는 아래 구조로 내부 지시를 구성한다.

```text
기준 이미지의 배경, 포즈, 카메라 앵글, 화면 비율, 인물 배치는 유지한다.
제공된 상품 이미지를 실제 착용한 것처럼 자연스럽게 합성한다.
상품의 컬러, 로고, 패턴, 형태는 원본 상품 이미지와 동일하게 유지한다.
모델의 체형, 주름, 조명, 그림자, 원근감에 맞춰 자연스럽게 적용한다.
사용자가 요청한 특정 변경 사항만 반영하고, 그 외 요소는 변경하지 않는다.
```

## 자주 쓰는 요청별 처리 규칙

### 1. 남녀 모델에게 서로 다른 상품 합성

- 남성/여성 구분을 먼저 한다.
- 상품 컬러와 로고가 바뀌지 않도록 한다.
- 두 모델의 조명과 상품 질감이 같은 촬영 환경처럼 보이게 맞춘다.

### 2. 모델 국적/인상 변경

- 사용자가 “외국인 모델”, “한국 모델”처럼 요청하면 얼굴과 인상만 자연스럽게 변경한다.
- 포즈, 의상 합성 결과, 배경, 구도는 유지한다.
- 특정 실존 인물처럼 만들지 않는다.

### 3. 로고 크기 수정

- 사용자가 “화이트 티셔츠 로고 크기와 동일하게”라고 하면 기준 로고의 시각적 면적을 맞춘다.
- 로고 색상 유지 요청이 있으면 색상은 절대 변경하지 않는다.
- 로고 위치는 상품 중심선 기준으로 자연스럽게 맞춘다.

### 4. 배경 확장 / 잘린 머리 복원

- 인물 크기를 키우거나 줄이지 않는다.
- 기존 배경의 하늘, 벽, 바닥, 조명 방향을 자연스럽게 연장한다.
- 잘린 머리나 신체 일부는 원래 촬영된 것처럼 자연스럽게 복원한다.
- 기존 화면의 분위기와 비율을 유지한다.

### 5. 텍스트/불필요한 오브젝트 제거

- 지정된 텍스트나 그래픽만 삭제한다.
- 상품 로고와 사용자가 유지하라고 한 요소는 삭제하지 않는다.
- 삭제 영역은 주변 배경과 자연스럽게 복원한다.

### 6. 상세페이지 인트로 이미지

- 사용자가 이미지 사이즈를 지정하면 그 사이즈를 따른다.
- 원본 상품 이미지는 변형하지 않는다.
- 부족한 영역은 배경을 확장해서 채운다.
- 상품 자체를 늘리거나 찌그러뜨리지 않는다.

## 기본 출력 사이즈 규칙

- 사용자가 사이즈를 지정하면 지정 사이즈를 우선한다.
- 상품 대표 이미지: 원본 비율 유지 또는 사용자가 지정한 비율
- 상세페이지 섹션 이미지: 기본 가로 860px, 세로 최소 1200px
- 상세페이지 인트로: 사용자가 지정한 사이즈 우선, 예: 950 x 1200
- 바탕화면/배너: 사용자가 지정한 비율 또는 픽셀 기준 우선

## 금지 사항

- 실제 상품 이미지와 다른 상품을 새로 만들어내지 않는다.
- 로고를 임의로 바꾸거나 제거하지 않는다.
- 사용자가 유지하라고 한 배경, 포즈, 비율을 임의로 변경하지 않는다.
- 모델의 자세를 크게 바꾸지 않는다.
- 상품 핏을 과장하거나 비현실적으로 만들지 않는다.
- 사용자가 요청하지 않은 텍스트를 추가하지 않는다.
- 특정 실존 인물의 얼굴로 바꾸지 않는다.

## 사용자에게 보여줄 응답 방식

이미지 생성 또는 편집 작업에서는 장황하게 설명하지 않는다.

- 이미지 생성 도구를 사용할 수 있으면 바로 실행한다.
- 이미지 생성 후에는 불필요한 설명을 붙이지 않는다.
- 오류가 있으면 사용자가 지적한 부분만 짧게 확인하고 해당 부분만 수정한다.

## 사용 예시

### 예시 1

사용자 요청:

```text
1번 이미지에 2번 3번 상품이미지를 모델에게 입혀서 합성해줘.
남성에게 화이트 상품, 여성에게 블랙 상품으로 합성.
1번의 배경이미지와 모델의 자세는 유지한다.
모델은 외국인 남녀 모델로 변경한다.
```

처리:

- 1번 이미지를 기준 이미지로 사용
- 남성 모델에게 화이트 상품 적용
- 여성 모델에게 블랙 상품 적용
- 배경과 포즈 유지
- 얼굴/인상만 외국인 모델 느낌으로 변경
- 상품 로고와 컬러 유지

### 예시 2

사용자 요청:

```text
블랙티셔츠의 로고 사이즈를 화이트티셔츠의 로고사이즈와 동일한 크기로 수정한다.
그 외 이미지의 변형 없이 유지해야 한다.
```

처리:

- 블랙 티셔츠 로고만 수정
- 화이트 티셔츠 로고의 시각적 크기를 기준으로 맞춤
- 로고 컬러는 기존 색상 유지
- 모델, 배경, 레이아웃, 상품 핏은 유지

### 예시 3

사용자 요청:

```text
인물의 크기는 유지하고 남자모델의 머리가 잘리는 부분을 복원하고 하늘 바탕이미지의 여백을 넣어 이미지를 확장한다.
```

처리:

- 인물 크기 유지
- 남성 모델 머리 잘림 복원
- 위쪽 또는 필요한 방향으로 하늘 배경 확장
- 기존 구도와 분위기 유지
